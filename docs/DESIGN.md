# デザイン

Figmaの編集可能なデザインを基に実装しています。

- [ライブラリ](https://www.figma.com/design/cLzXZKsOwSZVUjY6wOgmo1?node-id=2-2)
- [ボード](https://www.figma.com/design/cLzXZKsOwSZVUjY6wOgmo1?node-id=2-3)
- [作品詳細](https://www.figma.com/design/cLzXZKsOwSZVUjY6wOgmo1?node-id=2-4)

## 基本方針

初期案から、白黒を基調とした2色のUIと短い文言に変更しました。背景は `#f6f5f1`、文字と主要な操作は `#262722`。境界線や補助情報にはその濃淡を使います。長い見出しや説明文を減らし、Tabler Iconsと短いラベルで操作を示します。表示色と密度は設定から変更できます。

デスクトップはサイドバーと作品一覧の2領域で構成します。ギャラリー・リスト・ボードを切り替え、検索とタグの条件を共有します。ボードでは作品を自由に配置し、画面移動と拡大縮小で見比べます。

## 実装での調整

- Figmaの作品画像は「サンプル」と明記した図形です。アプリでは出典を記載したパブリックドメイン作品に置き換えています。サンプルのメモとコメントは練習用です。
- 作品詳細は一覧に戻りやすいダイアログにしました。スマートフォンでは画像とメモを縦に並べます。
- ボードの操作バーは画面下部にまとめました。狭い画面ではサイドバーをメニューに折りたたみます。
- 最初の画像生成案にあった長い見出しやオリーブ色の強調は採用していません。後から指定された2色と簡潔な文言を優先しています。
